Markdown in Jupyter Notebooks

  • Add a cell, then switch its type to Markdown (toolbar dropdown, or press M in command mode).
  • Press Shift+Enter to render the cell; double-click (or Enter) to edit it again.
  • Maths uses LaTeX: $E = mc^2$ inline, $$ ... $$ for display equations.
  • Raw HTML works inside Markdown cells, e.g. <span style="color:red">red</span>.
  • Images: ![alt](image.png) with a path relative to the notebook.
  • Link to another cell/heading using [text](#Heading-Name) (spaces become hyphens).
  • Tables are supported with the pipe syntax.
  • Jupyter does not support GitHub-only extras such as task lists, @mentions or emoji shortcodes.
  • Use the %%markdown cell magic in a code cell to render Markdown from code, or IPython.display.Markdown("**hi**").

Markdown on GitHub

  • Used in README.md files, issues, pull requests, comments, discussions and wikis.
  • Task lists: - [ ] todo and - [x] done.
  • Mention people and teams with @username; reference issues/PRs with #123.
  • Emoji shortcodes: :tada: becomes 🎉.
  • Fenced code blocks with a language get syntax highlighting: ```python.
  • Collapsible sections: <details><summary>Title</summary> ... </details>.
  • Alerts: start a blockquote with > [!NOTE], [!TIP], [!WARNING]…
  • Diagrams: a ```mermaid block renders a chart. Maths with $...$ also works.
  • GitHub renders .ipynb notebooks (including their Markdown cells) directly in the repo viewer.
  • Strikethrough ~~text~~, autolinked URLs and tables are all supported.
